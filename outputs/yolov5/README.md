# Recorded YOLOv5 output

This directory retains the compact numerical record from the original course experiment:

- `results.csv`: per-epoch training, validation, precision, recall, and mAP metrics
- `hyperparameters.yaml`: training hyperparameters recorded by YOLOv5

Selected plots and qualitative predictions are stored under `assets/` so they render directly in the main README. Checkpoints, TensorBoard event files, and complete generated run directories are excluded.
