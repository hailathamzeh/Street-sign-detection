# Asset attribution

The figures in this directory were retained from the original CIS 735 course project.

- Training plots, validation predictions, detection overlays, LIME figures, and SHAP figures were generated by the project notebooks.
- The underlying Jordanian traffic-sign data is attributed to Khaled Hweij's [Jordanian (Arabic) Traffic Signs in YOLO Format](https://www.kaggle.com/datasets/khaledhweij/jordanian-traffic-signs) dataset on Kaggle.
- The manual test images and short video were part of the original project materials. Some images retain visible third-party source marks. Their inclusion here is for academic demonstration and does not transfer ownership of the underlying imagery.
- YOLOv5 is a third-party project maintained by Ultralytics. Its source code is not vendored in this repository and remains subject to its own license.

Before reusing or redistributing an underlying image, review the current terms of its original source and the Kaggle dataset page.
